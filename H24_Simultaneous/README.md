## A. Literal finite H24 grammar: construct the calibration, do not enumerate proofs

Let J be the finite list of N distinct judgments. Each original labelled rule r has head h(r), an ordered finite list P(r) of premises (occurrences may repeat), and a positive natural charge c(r). All rules are explicitly listed. This theorem applies to finite cyclic grammars as well as DAGs. The restriction to strictly positive rule charges is material: zero-cost cycles may require an independent rank, as in the original `chainLoop` example.

Set V_0(j)=infinity for all j. Compute synchronously:

    V_(k+1)(j) = min(V_k(j), min_{r:h(r)=j} [c(r)+sum_{i in P(r)} V_k(i)]).

Arithmetic with infinity is strict; the empty sum is zero. Every finite table entry has an original backpointer, and every derivation of height <= k has charge at least V_k. This is an induction on k, using the root rule and all ordered child occurrences. Conversely an attaining tree of height <= k is constructed by choosing the first attaining rule and recursively reading the previous table (or retaining an already attained entry). A root-to-leaf path of a tree with repeated judgment admits a strictly cheaper replacement: replace the subtree at the first occurrence by the subtree at the later occurrence. The root type is unchanged and at least one positive-cost rule is removed. Repeat by decreasing natural work; the resulting tree has no repeated judgment on any branch and has height <= N. Therefore V_N is the minimum over **all** original finite derivations, with no arbitrary depth restriction on the competitor. None means no derivation. N is the size of the given judgment list, not the input size of an arbitrary implicitly presented grammar.

Let J+ be the set with finite V_N. Any rule all of whose premises are in J+ has its head in J+: otherwise their finite derivations would construct a derivation of that head. A rule with an unproductive premise cannot occur in any complete derivation. Thus retain exactly rules with productive premises, without dropping any valid original proof. The final values satisfy

    V(h(r)) <= c(r)+sum V(p),
    V(h(r)) = c(r)+sum V(p) for at least one rule at each productive head.

The second follows from an attaining tree and the first, replacing each child by a minimum. Scan the original rules in input order and retain a tight rule index at every productive head; retain every tie if the whole minimum fibre is requested. Each tight child satisfies V(p) <= sum V(p) < c(r)+sum V(p) = V(h), so rank=V. The original Lean `calibrationFromFeasible` constructs slack, `scannedPolicy` constructs a rank from that same potential, and `constructMinimum` constructs an original proof. `greatestFeasible` verifies that no other feasible natural potential exceeds the attained one. The Python certificate checker verifies closure, every original rule inequality, and each chosen rule's positive descending rank and exact equality. An induction over any derivation proves membership in J+ and the lower-bound property. Thus the certificate is sufficient independently of the algorithm that generated it.

For practical execution, store a DAG with one chosen rule per reachable productive judgment and labelled edges for every ordered premise occurrence. Rank proves acyclicity. Each original derivation is recovered by unfolding the shared DAG; the expanded tree is **not** promised polynomial size. The test grammar with rule 0 nullary and rule i requiring two copies of i-1 has min tree cost 2^N-1 but N DAG nodes. An H24 proof grade must not silently be identified with the clock of DAG construction. If the original receiver demands an expanded tree or materialized occurrence-specific data, charge that output. The Horn receiver below works on the DAG directly.

### Bit-work envelope

For a literal binary encoding of length L containing the N judgment records, R rules, A total premise occurrences, and charges, all N,R,A <= L after dense relabeling. Let a be maximum arity, c_max largest charge (take 1 if no rules). V_N <= c_max (a+1)^N when finite: a tree of height <= N has at most (a+1)^N nodes. Hence each value has O(log(c_max+1)+N log(a+1)) bits, conservatively O((L+1)^2). The synchronous fold uses at most N sweeps of R rules and A premise accesses; the Python implementation stops earlier only at a fixed table. A deterministic multitape implementation can use two sequential finite tables with explicit fixed-width cells for infinity/values, sequential scans for lookups/updates, dense identifiers and binary arithmetic. A table has O((L+1)^3) bits. Each lookup, comparison, addition and rule update can conservatively be performed in O((L+1)^4) bit transitions (including sequential scans and index comparisons). There are O((L+1)^2) such operations, including copying and final validation. Thus O((L+1)^6) is a conservative whole-constructor multitape bit bound; standard deterministic single-tape simulation still gives a polynomial (a quadratic simulation yields a coarse O((L+1)^12) bound). These are analytic implementation bounds, not measured Python bit steps and not tight. DAG traversal and output of at most N pointers and A occurrences fit the same envelope by scanning the tables. The supplied Lean table version scans rules separately for each judgment and is polynomial on explicit lists as well, with one additional factor N in the coarse scan bound; we did not measure its host execution or formalize that bit bound in Lean. The Lean `build` is an expanded derivation constructor, not the compressed DAG producer.

## B. The LP bridge: the actual calibration is a greatest feasible point

On the productive grammar solve the explicit real/rational LP

    maximize sum_{j in J+} x_j
    subject to x_j >= 0 and x_h <= c(r)+sum_{p in P(r)} x_p.

There are |J+| variables and at most |J+|+R rows, with integer entries and occurrence multiplicities. Induction on original derivations works for real x too: x_j <= work(tree). Hence every feasible x satisfies x_j <= V_N(j). The integral V_N is feasible and attains the maximum. Since each objective coefficient is strictly positive, it is the unique optimum. It follows that Theorem 1 of the attached *Strongly polynomial linear programming* (Nov 24, 2026) directly supplies a calibration solver **in the explicitly presented dimensions**, if one uses that external theorem. The DP above is a direct constructive alternative; it does not assume the paper's theorem, and this packet does not claim a Lean formalization of that paper. Section 3.4 of the paper distinguishes charged control and scalar operations, and Theorem 3 has proof-only scalings/demands: not every object used to prove a runtime need be constructed by the machine. Section 8/Theorem 8 and Corollary 9 require explicit dimension or a charged evaluation oracle; Corollary 12 covers max-plus linear inequalities, not arbitrary implicit proof search. General H24 rules with multi-premise sums have ordinary linear Bellman inequalities as above; unary rules give difference constraints.

This applies to any explicit grammar, and proves a polynomial procedure for acquiring the calibration in that case. It does NOT imply a polynomial-size presentation of every original SAT proof fibre. The simple assignment-expanded grammar is exponential. The polynomial-time result for explicit LP does not reduce the dimension of an arbitrary succinct CNF system. Example: the four clauses (x or y), (not x or y), (x or not y), (not x or not y) are jointly UNSAT, but the usual inequalities requiring sum of literal values >=1 admit x=y=1/2. Thus a direct continuous LP relaxation lacks the source-return equation even with exact optimization.

## C. A concrete NP family in P with original Čech return

Horn CNF: each original clause is b1 & ... & bk => h, with positive head h or bottom. Make one original rule with that body and head, charge 1, and add bottom as a judgment. No clauses are deleted. The explicit grammar has at most n+1 judgments, m rules, and total premise count at most the original literal length. Compute the certificate above.

If bottom is unproductive, set a variable true iff its judgment is productive. Closure under every rule proves that this assignment satisfies every original clause; all other models contain every productive variable (induction on a derivation), so this is the least model. If bottom is productive, return its selected original rule DAG. Under any alleged model, induction on its increasing-potential order forces every derived head true, including bottom, a contradiction. To return an original failure label on an arbitrary assignment, scan this DAG and find the first selected rule whose body is true and head false (bottom is false). At least one exists: if none existed, all selected derived heads would be true in order. The actual labelled clause is a failed-clause witness. This is a uniform finite function of the assignment and the DAG, not a list of all assignments. It supplies the selected label for the cone in the recovered `ReversibleH24.Cech.fibreCone` at every point of the fixed infinite base. The positive result provides an empty fibre by the satisfying assignment with a fixed tail and basepoints. No choice. This is an exact polynomial-time signed SAT/UNSAT producer on the Horn family. Its minimum is the minimum derivation-tree charge of a Horn judgment; it is not the minimum number of violated clauses over arbitrary assignments. Horn SAT is not asserted NP-complete.

## D. Cayley/Ramanujan and deterministic binary zero-gap probes

For any CNF define the original failed-clause vector f(a) in F2^m. The commuting involutions T_j(a,b)=(a,b xor f_j(a)) give an action of the abstract group F2^m on the marked rail. For a mask s in F2^m use T_s(a,b)=(a,b xor dot(s,f(a))). The regular Cayley character labelled y has eigenvalue (-1)^dot(s,y) on translation by s. The same scalar acts on the antisymmetric rail at a with y=f(a). Thus a relative spectral sparsifier on the original regular Cayley Laplacian transfers its eigenvalue inequalities to the marked action, even if the action is nonfaithful. In particular the relative PSD bound with 0<epsilon<1 preserves the exact kernel. If only reweighting/subsetting the m basis generators, no basis generator can be removed: the character e_j detects the missing one. This is not a lower bound on other generator systems. Hsieh et al. prove polylog(|G|)-size weighted Cayley sparsifiers, with randomized construction polynomial in |G|. Cohen's Ramanujan construction is deterministic polynomial in explicit graph size. These are distinct costs and representations.

Here is an additional deterministic construction, which preserves the zero test with a constant *normalized* gap, using polynomially many masks in m (it need not approximate the original nonzero eigenvalues). For m>=1 choose q=2^k with 2m<=q<4m. Construct F_q via a monic irreducible degree k polynomial; trial enumeration of candidates and factors of degree <=k/2 is polynomial in m, since q<4m. Use its binary coordinate vectors and the ordinary nondegenerate dot product over F2. For a,b in F_q put

    s(a,b)_j = dot(b, a^j), j=0,...,m-1.

For y in F2^m put P_y(X)=sum_j y_j X^j. If y!=0 it is a nonzero polynomial of degree <=m-1. The finite root bound gives <=m-1 roots in F_q. By character orthogonality,

    (1/q^2) sum_(a,b) (-1)^dot(s(a,b),y) = #roots(P_y)/q.

Indeed averaging b is 1 when P_y(a)=0 and 0 otherwise (pair b with b+e_i for a nonzero coordinate of P_y(a)). For y=0 the average is 1; otherwise it is <=(m-1)/q<1/2. The zero indicator energy

    E'(y) = (1/q^2) # {masks s : dot(s,y)=1}
          = (1-characterAverage(y))/2

is 0 at y=0 and in [1/4,1/2] otherwise. Use the original f(a) in this formula. The marked operator Q'_C is the antisymmetric compression of sum_s (I-T_s)/(2q^2). Its SAT zero sector is exactly ker Q_C, with a gap at least 1/4 on UNSAT. There are q^2=O(m^2) masks, each m bits; construction and all mask parity computations on supplied f(a) are deterministic polynomial in original length. Clause flags can be computed, reused in parity controlled swaps, and uncomputed; all addresses and readback charged. This is a multiset (loops and multiplicities retained), not a claim that the binary probe graph is Ramanujan or a relative approximation of the original cube. It replaces the weights by a zero-reflecting gap; original failed-clause count and positive minimizers must be retained separately. The empty-clause-list case m=0 has identically zero energy.

For the native six S3 frames the three-transposition Cayley graph K_{3,3} has spectrum 3,-3,0,0,0,0, hence bipartite Ramanujan. Its Laplacian divided by 3 has kernel constants and gap 1. Attach that graph as a tensor factor: Q'_C tensor I + I tensor L_frame, with kernel ker Q'_C tensor span(1). The S4 transposition frame can be used similarly with its normalized gap. This does not mix assignment labels and accidentally destroy the SAT kernel. The global read min_a E'(f(a)) remains the decision problem. Pointwise polynomial construction/evaluation plus constant gap alone does not provide that global read. In the black-box membership model, a deterministic oracle distinguisher of an identically zero function from one having a unique 1 must query every position on the all-zero run. This is a statement only about black-box acquisition, not about algorithms using the succinct formula syntax.
