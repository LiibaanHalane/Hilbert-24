## 3. Construct the ranking field from β

For a promised-side prefix `π`, put

\[
\beta_\pi=B(N)-A(C,\pi),\qquad
\Psi_\pi=\Phi(C,\pi)+\beta_\pi.
\tag{1}
\]

The first difference is formed in the integers. The prefix-budget field proves it is nonnegative, so both `β_π` and `Ψ_π` canonically inhabit `Nat`. There is no rounding or change of charge.

For an actual primitive tick, `A_{πe}=A_π+a_e`. Thus

\[
\begin{aligned}
1+\Psi_{\pi e}
 &=1+\Phi_{\pi e}+B-A_\pi-a_e\\
 &=a_e+\Phi_\pi+B-A_\pi-a_e\\
 &=\Psi_\pi.
\end{aligned}
\tag{2}
\]

For a macro this equation reads `w+Ψ_after=Ψ_before`. In particular, every actual live primitive tick decreases the natural reserve by exactly one, and every positive-cost macro strictly decreases it. Initially

\[
\Psi_0=\Phi_0+B(N)\le K(N)+B(N).
\tag{3}

To use an interface whose ranking is a function of a state rather than a prefix, take the reachable-state type to retain the source, its reachability witness and the ghost accumulator `A`. For the original H24 frontier, each amortized charge is a nonnegative calibration slack `σ`. Then `A` is a natural counter, `A+β=B`, and β decreases as slack is consumed. ### A subtraction-free local constructor

This is the exact local constructor for the checked `Ranking.decrease` field.

\qquad

\tag{5}

# The native torser judgment for an actual clocked shortest-verifier run

## 1. The judgment and the object it retains

Fix a deterministic bit machine (A), its original CNF input encoding, and
its actual primitive transition convention. A primitive transition reads and
writes a fixed finite set of tape-head bits, changes finite control, and moves
heads by at most one cell. The machine is fixed before the input. Literal
indices, clauses, assignments, output words, and verification steps belong to
its ordinary tape computation. Access to a distant encoded bit is performed
by that computation; it is not an additional unit-cost random-access primitive.

Write (s\mathrel{\leadsto_A}s') for **one such executed transition**. A
recorded configuration is

\[
 x=(C,s,H),\qquad \tau(x)=|H|.
\]

Here (C) is the unchanged original input and (H) is the chronological
history of executed primitive events. A history event has a fixed finite
alphabet depending on (A): previous control, overwritten head symbols and
head directions suffice. It does not contain a copied whole tape. Appending
one event is performed at the end of a separate history tape. The inverse
restores the old heads, symbols and control from the last event. Consequently

\[
 f_A(C,s,H)=(C,s',H\mathbin{\|}e_A(s))
\tag{1}
\]

is injective on its live domain. The inverse is defined on its actual image.
A halting state has no executed successor in this relation.

The source clock is the **marked natural number** (|H|). It is not obtained
by declaring arbitrary-precision integer addition a single transition. It may
remain the length of the event stream. If a program materializes its binary
numeral, copies the complete history, evaluates a matrix entry, prints a proof,
or runs another verifier, all those instructions are additional executed
events. Equation (1) is a record-preserving simulation: a fixed reversible
implementation uses a fixed number of local bit transitions per source step,
with its own initial/final overhead. Source ticks and implementation ticks are
two explicitly related counts, not silently identified numbers.

The new native judgment is

\[
 \mathsf{NT}_A(C;x\xRightarrow[p]{,k,}y).
\tag{2}
\]

It means that (p) is a derivation from the rules below, its represented
execution starts at (x), ends at (y), retains (C), and contains exactly
(k) original primitive bit transitions. A terminal version is

\[
 \mathsf{NTMin}_A(C;q,k):=
 \sum_{x,y,p}\mathsf{NT}_A(C;x\xRightarrow[p]{k}y)
 \times\mathsf{Initial}_A(C,x)\times\mathsf{Halt}_A(y)
 \times[\mathsf{output}(y)=q]\times\mathsf{Shortest}_{V_*}(C,q).
\tag{3}
\]

The final field is the original fixed-verifier minimum, not a native surrogate.
The existing source has

\[
 V_*(C,q)\iff
 q=1\,0^{n+1}\quad\lor\quad
 \exists a\in\{0,1\}^n\;(q=0a\ \land\ C(a)=1).
\tag{4}
\]

Its structural constructor already proves that its emitted code is a minimum
among **all** words accepted by this (V_*). The new construction transports
that proof and the actual execution; it does not assume a polynomial SAT
algorithm.

## 2. Rules that construct the native execution proof

The proof syntax is generated by the following constructors.

**Identity.** The unchanged configuration has a zero-transition proof:

\[
 \frac{}{\mathsf{NT}_A(C;x\xRightarrow{0}x)}.
\]

**Actual tick.** A literal transition of the fixed machine gives

\[
 \frac{s\leadsto_A s'}
 {\mathsf{NT}_A(C;(C,s,H)\xRightarrow{1}
                  (C,s',H\mathbin{\|}e_A(s)))}.
\]

**Costed composition.** Matching middle configurations give

\[
 \frac{\mathsf{NT}_A(C;x\xRightarrow{k}y)\qquad
       \mathsf{NT}_A(C;y\xRightarrow{l}z)}
 {\mathsf{NT}_A(C;x\xRightarrow{k+l}z)}.
\]

The displayed addition is an equality of mathematical grades. This constructor
does not execute a hidden arbitrary-precision addition at unit cost. If a
running implementation computes that grade, its computation is represented by
further ticks.

**Pure change of presentation.** A proved equality of two descriptions of the
same retained record may replace one description by the other at zero added
execution cost. It changes neither (s), (H), nor the original output. A
real conversion program, frame-update instruction, matrix materialization or
copy is represented by its ticks instead. This rule is therefore unavailable
for an unevaluated coefficient operator.

**Local reserve.** A natural reserve (\Phi) and natural slack (\eta) satisfy
the upper-work rule precisely when

\[
 1+\Phi(f_Ax)+\eta(x)=\Phi(x)
\tag{5}
\]

at the actual live state. It is tight when (\eta(x)=0). For a macro of
already established cost (c(x)), replace (1) by (c(x)). No assertion
that such a reserve exists on all inputs is built into this rule.

**Terminal readback.** A valid halting execution, an equality of its actual
output with the output of a checked original receipt, and the existing
structural receipt theorem construct (3). In the source notation the premise
is

\[
 \mathsf{rrOK}(C,\epsilon,n,h),\qquad
 \mathsf{output}(y)=\mathsf{rrEmit}(C,h).
\]

`rr_root_receipt_gives_minimum` then supplies the last field of (3). This is
a mathematical proof rule. It does not request an uncharged runtime oracle
that tests whether an arbitrary code is shortest. Any actual checker called
by (A) has already contributed its transitions to (H).

### The complete clock invariant

Induction on these constructors proves

\[
 \tau(y)=\tau(x)+k.
\tag{6}
\]

For identity, (6) is addition by zero. For a tick it is the defining history
extension. For composition, substitute the two induction hypotheses and use
associativity of natural addition. Presentation equality changes no record.
Terminal readback adds no execution. The same induction proves equality of
the original input at the two endpoints and exact preservation of the output
field.

Applying the local reserve rule at every actual tick and inducting on the

\[
 k+\Phi(y)+\sum_{x_i\text{ executed}}\eta(x_i)=\Phi(x).
\tag{7}
\]

Every term on the left is a marked natural number. Thus (k\le\Phi(x)).
This is an **upper** execution bound. The H24 lower calibration has the

\[
 \mathsf{ruleCost}+V(\mathsf{premises})

its dagger followed by itself is the projection on its actual source domain;
the opposite product is projection on its actual image. This is the inverse
of the history-preserving step on that image.

The clock shear is different. Direct calculation gives

\[
 U(k)^\dagger_G=
 \begin{pmatrix}1+2k/3&-k/3\\4k/3&1-2k/3\end{pmatrix},
 \qquad U(k)^{-1}=U(-k).
\tag{21}
\]

These generally differ. The complete clocked matrix has an exact dagger and
an exact decoder, but recording elapsed work is not declared a unitary data
operation. Reading the adjoint does not mean executing a negative-time run.
The inverse (U(-k)) is an algebraic comparison; actual reverse execution,
when requested, consists of its own positive-cost primitive steps.

## 6. Fredkin and Toffoli are actual local operational blocks

The inherited source uses

\[
 \mathrm F(c,a,b)=
 \begin{cases}(0,a,b)&c=0,\\(1,b,a)&c=1,\end{cases}
 \qquad
 \mathrm T(c,a,t)=(c,a,t\oplus ca).
\tag{22}
\]

Both are involutions on their actual three original wires. The source proves
these equations by the Boolean constructors and retains the challenged
original variable and clause labels. With fixed constants, Toffoli returns
AND, NAND and NOT, and Fredkin returns OR and the marked mux. This is the
existing `CechReversibleGates` interface, not a newly postulated gate action.

For a fixed machine (A), its finite local transition table is a finite
Boolean function of the control and head symbols. Write each output bit by
its finite truth formula. Each AND is obtained by Toffoli on a clean target,
NOT by a controlled constant wire, and copying by the corresponding XOR gate
with constant control. Retain inputs and old control until outputs and the
finite history event have been recorded; reverse temporary gates to clean
workspace. Fixed head moves are genuine local tape moves. This constructs a
reversible finite block for every source transition.

All truth-formula, workspace and motion sizes depend on the fixed machine,
not on (C). Let its actual compiled bit-transition list have length
(\kappa_A(e)). The native matrix of that block has cost
(\kappa_A(e)) by (13), not cost one merely because it has one source name.
For a source run (e_1,\ldots,e_k),

\[
 W_{\widehat A}(C)=W_{\rm init}(C)
     +\sum_{i=1}^k\kappa_A(e_i)+W_{\rm final}(C).
\tag{23}
\]

In particular (kappa_A=\max_e\kappa_A(e)) gives the proved simulation
bound. Setup, output, verification and readback in this implementation are
included in the two overhead terms or in the event lists. A request to treat
an arbitrary decoded program as an input changes the machine to an interpreter
and uses that interpreter's actual step costs. No nonuniform constant is
allowed to vary with the individual CNF.

## 7. The shortest-verifier bridge is now a native H24 conclusion

\[
 (C,q,H,k,\pi_{\rm run},\pi_{\rm min})
\]

exactly; in particular it returns the original assignment when (q=0a), or

import Hilbert24_Calibrated_Policy

/-!
H24 for the actual execution of a proof/certificate GENERATOR.

`next` denotes one actual primitive bit transition of that implementation,
including rule selection, cofactor acquisition, checking, and output/readback.
This machine is not an interpreter that merely executes the proof it emits.
The interpretation of a primitive tick is a source interface, not inferred
from a code-length grade or from the number of outer cofactor calls.

All construction below is recursion on the supplied LOCAL operational reserve.
No halting answer, complete run, minimum proof, or global clock is a field of
`Ranking`. The remaining source-uniform reserve field is named separately.
-/

namespace H24OperationalBridge

universe u v w

structure BitMachine (State : Type u) where
  next : State → Option State

structure Ranking {State : Type u} (M : BitMachine State) where
  reserve : State → Nat
  decrease : ∀ s t, M.next s = some t → reserve t < reserve s

/-- Actual tick count, constructed by following the original bit transition. -/
def remaining {State : Type u} {M : BitMachine State} (R : Ranking M)
    (s : State) : Nat :=
  match h : M.next s with
  | none => 0
  | some t => 1 + remaining R t
termination_by R.reserve s
decreasing_by exact R.decrease s t h

theorem remaining_halt {State : Type u} {M : BitMachine State} (R : Ranking M)
    (s : State) (h : M.next s = none) : remaining R s = 0 := by
  rw [remaining]
  split
  · rfl
  · rename_i t ht
    have impossible : (none : Option State) = some t := h.symm.trans ht
    cases impossible

theorem remaining_tick {State : Type u} {M : BitMachine State} (R : Ranking M)
    (s t : State) (h : M.next s = some t) :
    remaining R s = 1 + remaining R t := by
  rw [remaining]
  split
  · rename_i hn
    have impossible : (some t : Option State) = none := h.symm.trans hn
    cases impossible
  · rename_i q hq
    have equal : t = q := Option.some.inj (h.symm.trans hq)
    cases equal
    rfl

/-- The source operational grammar has exactly its original halt/tick rules. -/
inductive Rule {State : Type u} (M : BitMachine State) : Type u
  | halt (s : State) (actual : M.next s = none)
  | tick (s t : State) (actual : M.next s = some t)

def system {State : Type u} (M : BitMachine State) :
    Hilbert24Policy.RuleSystem State where
  Rule := Rule M
  conclusion
    | .halt s _ => s
    | .tick s _ _ => s
  arity
    | .halt _ _ => 0
    | .tick _ _ _ => 1
  premise
    | .halt _ _, i => Fin.elim0 i
    | .tick _ t _, _ => t
  charge
    | .halt _ _ => 0
    | .tick _ _ _ => 1

def calibration {State : Type u} {M : BitMachine State} (R : Ranking M) :
    Hilbert24Policy.Calibration (system M) where
  potential := remaining R
  slack := fun _ => 0
  local_identity := by
    intro r
    cases r with
    | halt s h =>
        change 0 = remaining R s
        exact (remaining_halt R s h).symm
    | tick s t h =>
        change 1 + remaining R t = remaining R s
        exact (remaining_tick R s t h).symm

def chosen {State : Type u} (M : BitMachine State) (s : State) :
    {r : Rule M // (system M).conclusion r = s} :=
  match h : M.next s with
  | none => ⟨.halt s h, rfl⟩
  | some t => ⟨.tick s t h, rfl⟩

def policy {State : Type u} {M : BitMachine State} (R : Ranking M) :
    Hilbert24Policy.TightPolicy (system M) (calibration R) where
  chosen := chosen M
  tight := fun _ => rfl
  rank := R.reserve
  decrease := by
    intro s
    unfold chosen
    split
    next h =>
      intro i
      exact Fin.elim0 i
    next t h =>
      intro _
      exact R.decrease s t h

/-- A source execution retains every actual intermediate state and transition. -/
inductive Execution {State : Type u} (M : BitMachine State) : State → Type u
  | halt (s : State) (actual : M.next s = none) : Execution M s
  | tick (s t : State) (actual : M.next s = some t)
      (tail : Execution M t) : Execution M s

def ticks {State : Type u} {M : BitMachine State} :
    {s : State} → Execution M s → Nat
  | _, .halt _ _ => 0
  | _, .tick _ _ _ tail => 1 + ticks tail

def finish {State : Type u} {M : BitMachine State} :
    {s : State} → Execution M s → State
  | _, .halt s _ => s
  | _, .tick _ _ _ tail => finish tail

theorem finish_halted {State : Type u} {M : BitMachine State} {s : State}
    (e : Execution M s) : M.next (finish e) = none := by
  induction e with
  | halt s h => exact h
  | tick s t h tail ih => exact ih

/-- Actual source-rule interpretation; it returns a run, not a mere cost. -/
def ruleReturn {State : Type u} {M : BitMachine State}
    (r : Rule M)
    (children : (i : Fin ((system M).arity r)) →
      Execution M ((system M).premise r i)) : Execution M ((system M).conclusion r) :=
  match r with
  | .halt s h => .halt s h
  | .tick s t h => .tick s t h (children ⟨0, Nat.zero_lt_succ 0⟩)

def decode {State : Type u} {M : BitMachine State} {s : State}
    (p : Hilbert24Policy.Derivation (system M) s) : Execution M s :=
  Hilbert24Policy.interpret (Execution M) ruleReturn p

theorem decode_ticks {State : Type u} {M : BitMachine State} {s : State}
    (p : Hilbert24Policy.Derivation (system M) s) :
    ticks (decode p) = Hilbert24Policy.work p := by
  induction p with
  | node r children ih =>
      cases r with
      | halt s h => rfl
      | tick s t h =>
          simpa [decode, ticks, Hilbert24Policy.work, system, Hilbert24Policy.sumFin]
            using congrArg (fun n => 1 + n) (ih ⟨0, Nat.zero_lt_succ 0⟩)

/-- H24's total constructor applied to the actual bit-machine source grammar. -/
def putRunInH24 {State : Type u} {M : BitMachine State} (R : Ranking M)
    (s : State) : Hilbert24Policy.OptimalReturn (system M) (calibration R) s :=
  Hilbert24Policy.constructMinimum (policy R) s

def sourceRun {State : Type u} {M : BitMachine State} (R : Ranking M)
    (s : State) : Execution M s := decode (putRunInH24 R s).derivation

theorem sourceRun_exact {State : Type u} {M : BitMachine State}
    (R : Ranking M) (s : State) : ticks (sourceRun R s) = remaining R s := by
  rw [sourceRun, decode_ticks]
  exact (putRunInH24 R s).exact_cost

theorem sourceRun_minimum {State : Type u} {M : BitMachine State}
    (R : Ranking M) (s : State)
    (q : Hilbert24Policy.Derivation (system M) s) :
    ticks (sourceRun R s) ≤ Hilbert24Policy.work q := by
  rw [sourceRun, decode_ticks]
  exact (putRunInH24 R s).optimal q

/-- Local one-bit decrease pays for all actual ticks by induction. -/
theorem remaining_le_reserve {State : Type u} {M : BitMachine State}
    (R : Ranking M) (s : State) : remaining R s ≤ R.reserve s := by
  generalize hr : R.reserve s = n
  induction n using Nat.strongRecOn generalizing s with
  | ind n ih =>
      cases h : M.next s with
      | none => rw [remaining_halt R s h]; exact Nat.zero_le _
      | some t =>
          rw [remaining_tick R s t h]
          have ht := R.decrease s t h
          have it : remaining R t ≤ R.reserve t :=
            ih (R.reserve t) (by simpa [hr] using ht) t rfl
          exact Nat.le_trans (Nat.add_le_add_left it 1)
            (by simpa only [Nat.succ_eq_add_one, Nat.add_comm, hr] using Nat.succ_le_of_lt ht)

theorem sourceRun_paid {State : Type u} {M : BitMachine State}
    (R : Ranking M) (s : State) : ticks (sourceRun R s) ≤ R.reserve s := by
  rw [sourceRun_exact]
  exact remaining_le_reserve R s

/-- The executable bounded wrapper uses input and fuel, never a negative proof. -/
def runFor {State : Type u} (M : BitMachine State) : Nat → State → State
  | 0, s => s
  | n+1, s => match M.next s with
    | none => s
    | some t => runFor M n t

theorem runFor_halt {State : Type u} (M : BitMachine State) (n : Nat)
    (s : State) (h : M.next s = none) : runFor M n s = s := by
  cases n with
  | zero => rfl
  | succ n => rw [runFor, h]

theorem execution_runFor {State : Type u} {M : BitMachine State} {s : State}
    (e : Execution M s) : runFor M (ticks e) s = finish e := by
  induction e with
  | halt s h => rfl
  | tick s t h tail ih =>
      simpa [ticks, finish, Nat.add_comm, runFor, h] using ih

theorem runFor_add {State : Type u} (M : BitMachine State) (m n : Nat)
    (s : State) : runFor M (m+n) s = runFor M n (runFor M m s) := by
  induction m generalizing s with
  | zero => exact congrArg (fun k => runFor M k s) (Nat.zero_add n)
  | succ m ih =>
      cases h : M.next s with
      | none =>
          rw [runFor_halt M (m+1+n) s h, runFor_halt M (m+1) s h,
            runFor_halt M n s h]
      | some t => simpa [Nat.succ_add, runFor, h] using ih t

theorem execution_within {State : Type u} {M : BitMachine State} {s : State}
    (e : Execution M s) (budget : Nat) (h : ticks e ≤ budget) :
    runFor M budget s = finish e := by
  have splitBudget : ticks e + (budget - ticks e) = budget :=
    Hilbert24Policy.add_sub_of_le_constructive h
  rw [← splitBudget, runFor_add, execution_runFor]
  exact runFor_halt M (budget - ticks e) (finish e) (finish_halted e)

/-- A simulation maps each actual counted tick, including its source labels. -/
def mapExecution {S : Type u} {T : Type v} {M : BitMachine S} {N : BitMachine T}
    (f : S → T) (step : ∀ s, (M.next s).map f = N.next (f s)) :
    {s : S} → Execution M s → Execution N (f s)
  | _, .halt s h => .halt (f s) (by rw [← step, h]; rfl)
  | _, .tick s t h tail => .tick (f s) (f t)
      (by rw [← step, h]; rfl) (mapExecution f step tail)

theorem mapExecution_ticks {S : Type u} {T : Type v}
    {M : BitMachine S} {N : BitMachine T}
    (f : S → T) (step : ∀ s, (M.next s).map f = N.next (f s))
    {s : S} (e : Execution M s) : ticks (mapExecution f step e) = ticks e := by
  induction e with
  | halt s h => rfl
  | tick s t h tail ih => exact congrArg (fun n => 1+n) ih

theorem mapExecution_finish {S : Type u} {T : Type v}
    {M : BitMachine S} {N : BitMachine T}
    (f : S → T) (step : ∀ s, (M.next s).map f = N.next (f s))
    {s : S} (e : Execution M s) : finish (mapExecution f step e) = f (finish e) := by
  induction e with
  | halt s h => rfl
  | tick s t h tail ih => exact ih

inductive Reachable {S : Type u} (M : BitMachine S) (start : S) : S → Prop
  | initial : Reachable M start start
  | advance {s t : S} : Reachable M start s → M.next s = some t → Reachable M start t

def reachedMachine {S : Type u} (M : BitMachine S) (start : S) :
    BitMachine {s : S // Reachable M start s} where
  next q := match h : M.next q.val with
    | none => none
    | some t => some ⟨t, Reachable.advance q.property h⟩

def reachedStart {S : Type u} (M : BitMachine S) (start : S) :
    {s : S // Reachable M start s} := ⟨start, .initial⟩

theorem reached_projection {S : Type u} (M : BitMachine S) (start : S)
    (q : {s : S // Reachable M start s}) :
    ((reachedMachine M start).next q).map Subtype.val = M.next q.val := by
  dsimp only [reachedMachine]
  split
  · rename_i h
    exact h.symm
  · rename_i t h
    exact h.symm

def eraseReach {S : Type u} {M : BitMachine S} {start : S}
    {q : {s : S // Reachable M start s}} (e : Execution (reachedMachine M start) q) :
    Execution M q.val := mapExecution Subtype.val (reached_projection M start) e

theorem runFor_reachable {S : Type u} (M : BitMachine S) (start : S)
    (n : Nat) (s : S) (hs : Reachable M start s) :
    Reachable M start (runFor M n s) := by
  induction n generalizing s with
  | zero => exact hs
  | succ n ih =>
      cases h : M.next s with
      | none => simpa [runFor, h] using hs
      | some t => simpa [runFor, h] using ih t (Reachable.advance hs h)

/-- The original checked-negative generator implementation, fixed before inputs.
    `machine.next` is its complete actual bit transition. It includes execution
    of rule selection, cofactor acquisition, checking, and readback. A terminal
    here is a recognized checked negative event, not an unverified label. On
    positive inputs the monitored machine may keep running. `readReceipt`
    interprets only an ACTUALLY reached terminal state; no receipt is an input. -/
structure GeneratorImplementation (Input : Type u) (State : Type v) where
  machine : BitMachine State
  initial : Input → State
  inputBits : Input → Nat
  Negative : Input → Prop
  SourceReceipt : Input → Type w
  readReceipt : ∀ C s, Reachable machine (initial C) s →
    machine.next s = none → SourceReceipt C
  receipt_sound : ∀ C, SourceReceipt C → Negative C

abbrev ReachMachine {Input : Type u} {State : Type v}
    (G : GeneratorImplementation.{u,v,w} Input State) (C : Input) :=
  reachedMachine G.machine (G.initial C)

abbrev Initial {Input : Type u} {State : Type v}
    (G : GeneratorImplementation.{u,v,w} Input State) (C : Input) :=
  reachedStart G.machine (G.initial C)

/-- This is the explicit remaining SOURCE field. c,d are chosen once, before
    every C. Ranking is required only for reached states on Negative inputs.
    It does not assert a bound on the emitted proof's code grade. -/
structure UniformReserve {Input : Type u} {State : Type v}
    (G : GeneratorImplementation.{u,v,w} Input State) where
  coefficient : Nat
  degree : Nat
  positive : 0 < coefficient
  ranking : ∀ C, G.Negative C → Ranking (ReachMachine G C)
  initial_bound : ∀ C h, (ranking C h).reserve (Initial G C) ≤
    coefficient * (G.inputBits C + 1)^degree

/-- Named open source judgement, ready for an exact torser presentation. -/
def UniformReserveTarget {Input : Type u} {State : Type v}
    (G : GeneratorImplementation.{u,v,w} Input State) : Prop := Nonempty (UniformReserve G)

def deadline {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (B : UniformReserve G) (C : Input) :=
  B.coefficient * (G.inputBits C + 1)^B.degree

/-- The explicit H24 entry point for the bridge. Negative evidence occurs only
    in the termination proof interface. The bit transition remains G.machine. -/
def putBridgeInH24 {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (B : UniformReserve G)
    (C : Input) (h : G.Negative C) := putRunInH24 (B.ranking C h) (Initial G C)

def generatedRun {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (B : UniformReserve G)
    (C : Input) (h : G.Negative C) : Execution G.machine (G.initial C) :=
  eraseReach (decode (putBridgeInH24 B C h).derivation)

theorem generatedRun_grade {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (B : UniformReserve G)
    (C : Input) (h : G.Negative C) : ticks (generatedRun B C h) =
      Hilbert24Policy.work (putBridgeInH24 B C h).derivation := by
  rw [generatedRun, eraseReach, mapExecution_ticks, decode_ticks]

theorem generatedRun_deadline {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (B : UniformReserve G)
    (C : Input) (h : G.Negative C) : ticks (generatedRun B C h) ≤ deadline B C := by
  rw [generatedRun_grade]
  have paid := sourceRun_paid (B.ranking C h) (Initial G C)
  have paidH24 : Hilbert24Policy.work (putBridgeInH24 B C h).derivation ≤
      (B.ranking C h).reserve (Initial G C) := by
    simpa [sourceRun, decode_ticks, putBridgeInH24] using paid
  exact Nat.le_trans paidH24 (B.initial_bound C h)

theorem generatedRun_minimum {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (B : UniformReserve G)
    (C : Input) (h : G.Negative C)
    (q : Hilbert24Policy.Derivation (system (ReachMachine G C)) (Initial G C)) :
    ticks (generatedRun B C h) ≤ Hilbert24Policy.work q := by
  rw [generatedRun_grade]
  exact (putBridgeInH24 B C h).optimal q

theorem generatedRun_is_actual_wrapper {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (B : UniformReserve G)
    (C : Input) (h : G.Negative C) :
    runFor G.machine (deadline B C) (G.initial C) = finish (generatedRun B C h) :=
  execution_within (generatedRun B C h) (deadline B C) (generatedRun_deadline B C h)

/-- The clock conclusion retains the original source machine and input. -/
structure UniformDeadline {Input : Type u} {State : Type v}
    (G : GeneratorImplementation.{u,v,w} Input State) where
  coefficient : Nat
  degree : Nat
  positive : 0 < coefficient
  hit : ∀ C, G.Negative C →
    G.machine.next (runFor G.machine (coefficient * (G.inputBits C + 1)^degree)
      (G.initial C)) = none

def UniformDeadlineTarget {Input : Type u} {State : Type v}
    (G : GeneratorImplementation.{u,v,w} Input State) : Prop := Nonempty (UniformDeadline G)

def bridgeDeadline {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (B : UniformReserve G) :
    UniformDeadline G where
  coefficient := B.coefficient
  degree := B.degree
  positive := B.positive
  hit C h := by
    change G.machine.next (runFor G.machine (deadline B C) (G.initial C)) = none
    rw [generatedRun_is_actual_wrapper B C h]
    exact finish_halted (generatedRun B C h)

theorem named_source_bridge {Input : Type u} {State : Type v}
    (G : GeneratorImplementation.{u,v,w} Input State) :
    UniformReserveTarget G → UniformDeadlineTarget G := by
  intro ⟨B⟩
  exact ⟨bridgeDeadline B⟩

def returnedReceipt {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (B : UniformReserve G)
    (C : Input) (h : G.Negative C) : G.SourceReceipt C :=
  G.readReceipt C (runFor G.machine (deadline B C) (G.initial C))
    (runFor_reachable G.machine (G.initial C) (deadline B C) (G.initial C) .initial)
    ((bridgeDeadline B).hit C h)

/-- One executable timeout decision from the constructed deadline. It receives
    C, fixed A=G.machine and c,d. No negative evidence is an executed input. -/
def decideNegative {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (D : UniformDeadline G)
    (C : Input) : Decidable (G.Negative C) :=
  let n := D.coefficient * (G.inputBits C + 1)^D.degree
  let s := runFor G.machine n (G.initial C)
  match h : G.machine.next s with
  | none => isTrue (G.receipt_sound C (G.readReceipt C s
      (runFor_reachable G.machine (G.initial C) n (G.initial C) .initial) h))
  | some t => isFalse (fun negative => by
      have stop := D.hit C negative
      change G.machine.next s = none at stop
      rw [h] at stop
      cases stop)

/-- Exact retained native presentation. A separate native implementation must
    supply its actual microstep costs; encode/decode computation is not silently
    declared free by this record. Here the SAME source execution is represented. -/
structure ExactChart (Source : Type u) (Native : Type v) where
  write : Source → Native
  read : Native → Source
  read_write : ∀ x, read (write x) = x
  write_read : ∀ y, write (read y) = y

def nativeMachine {S : Type u} {N : Type v} (E : ExactChart S N)
    (M : BitMachine S) : BitMachine N where
  next n := (M.next (E.read n)).map E.write

theorem native_tick_square {S : Type u} {N : Type v} (E : ExactChart S N)
    (M : BitMachine S) (s : S) :
    (M.next s).map E.write = (nativeMachine E M).next (E.write s) := by
  change (M.next s).map E.write = (M.next (E.read (E.write s))).map E.write
  rw [E.read_write]

def nativeRun {S : Type u} {N : Type v} (E : ExactChart S N)
    {M : BitMachine S} {s : S} (e : Execution M s) :
    Execution (nativeMachine E M) (E.write s) :=
  mapExecution E.write (native_tick_square E M) e

theorem nativeRun_grade {S : Type u} {N : Type v} (E : ExactChart S N)
    {M : BitMachine S} {s : S} (e : Execution M s) : ticks (nativeRun E e) = ticks e :=
  mapExecution_ticks E.write (native_tick_square E M) e

theorem nativeRun_return {S : Type u} {N : Type v} (E : ExactChart S N)
    {M : BitMachine S} {s : S} (e : Execution M s) :
    E.read (finish (nativeRun E e)) = finish e := by
  rw [nativeRun, mapExecution_finish, E.read_write]

def putNativeBridgeInH24 {Input : Type u} {State : Type v} {Native : Type w}
    {G : GeneratorImplementation Input State} (E : ExactChart State Native)
    (B : UniformReserve G) (C : Input) (h : G.Negative C) :=
  nativeRun E (generatedRun B C h)

theorem native_bridge_deadline {Input : Type u} {State : Type v} {Native : Type w}
    {G : GeneratorImplementation Input State} (E : ExactChart State Native)
    (B : UniformReserve G) (C : Input) (h : G.Negative C) :
    ticks (putNativeBridgeInH24 E B C h) ≤ deadline B C := by
  rw [putNativeBridgeInH24, nativeRun_grade]
  exact generatedRun_deadline B C h

/-- The WHOLE source reserve witness, including fixed c,d and its universal
    input family, may be represented. A partial input-specific fragment is not
    substituted for this source judgement. -/
def NativeReserveTarget {Input : Type u} {State : Type v} {Native : Type w}
    {G : GeneratorImplementation Input State}
    (_E : ExactChart (UniformReserve G) Native) : Prop := Nonempty Native

theorem native_reserve_target_exact {Input : Type u} {State : Type v} {Native : Type w}
    {G : GeneratorImplementation Input State} (E : ExactChart (UniformReserve G) Native) :
    NativeReserveTarget E ↔ UniformReserveTarget G := by
  constructor
  · intro ⟨n⟩; exact ⟨E.read n⟩
  · intro ⟨b⟩; exact ⟨E.write b⟩

theorem native_reserve_readback {Input : Type u} {State : Type v} {Native : Type w}
    {G : GeneratorImplementation Input State} (E : ExactChart (UniformReserve G) Native)
    (B : UniformReserve G) : E.read (E.write B) = B := E.read_write B

def constructFromNativeReserve {Input : Type u} {State : Type v} {Native : Type w}
    {G : GeneratorImplementation Input State} (E : ExactChart (UniformReserve G) Native)
    (n : Native) : UniformDeadline G := bridgeDeadline (E.read n)

end H24OperationalBridge

def boundedTicks {S : Type u} (M : BitMachine S) : Nat → S → Nat
  | 0, _ => 0
  | n+1, s => match M.next s with
    | none => 0
    | some t => 1 + boundedTicks M n t

theorem boundedTicks_halt {S : Type u} (M : BitMachine S) (n : Nat)
    (s : S) (h : M.next s = none) : boundedTicks M n s = 0 := by
  cases n with
  | zero => rfl
  | succ n => rw [boundedTicks, h]

theorem boundedTicks_tick {S : Type u} (M : BitMachine S) (n : Nat)
    (s t : S) (h : M.next s = some t) :
    boundedTicks M (n+1) s = 1 + boundedTicks M n t := by
  rw [boundedTicks, h]

theorem boundedTicks_le {S : Type u} (M : BitMachine S) (n : Nat)
    (s : S) : boundedTicks M n s ≤ n := by
  induction n generalizing s with
  | zero => exact Nat.le_refl 0
  | succ n ih =>
      cases h : M.next s with
      | none => rw [boundedTicks_halt M (n+1) s h]; exact Nat.zero_le _
      | some t =>
          rw [boundedTicks_tick M n s t h, Nat.add_comm 1]
          exact Nat.succ_le_succ (ih t)

theorem halted_after_extra {S : Type u} (M : BitMachine S) (n k : Nat)
    (s : S) (h : M.next (runFor M n s) = none) :
    M.next (runFor M (n+k) s) = none := by
  rw [runFor_add, runFor_halt M k (runFor M n s) h]
  exact h

theorem boundedTicks_stable {S : Type u} (M : BitMachine S) (n : Nat)
    (s : S) (h : M.next (runFor M n s) = none) :
    boundedTicks M (n+1) s = boundedTicks M n s := by
  induction n generalizing s with
  | zero => exact boundedTicks_halt M 1 s h
  | succ n ih =>
      cases hs : M.next s with
      | none => rw [boundedTicks_halt M (n+1+1) s hs, boundedTicks_halt M (n+1) s hs]
      | some t =>
          rw [runFor, hs] at h
          rw [boundedTicks_tick M (n+1) s t hs, boundedTicks_tick M n s t hs]
          exact congrArg (fun k => 1+k) (ih t h)

theorem halted_tail {S : Type u} (M : BitMachine S) (n : Nat)
    (s t : S) (step : M.next s = some t)
    (h : M.next (runFor M n s) = none) : M.next (runFor M n t) = none := by
  cases n with
  | zero =>
      change M.next s = none at h
      rw [step] at h
      cases h
  | succ n =>
      rw [runFor, step] at h
      exact halted_after_extra M n 1 t h

theorem reached_halted_by_same_deadline {S : Type u} (M : BitMachine S)
    (n : Nat) (start : S) (h : M.next (runFor M n start) = none)
    (s : S) (reachable : Reachable M start s) : M.next (runFor M n s) = none := by
  induction reachable with
  | initial => exact h
  | @advance s t previous step ih => exact halted_tail M n s t step ih

theorem boundedTicks_decreases {S : Type u} (M : BitMachine S) (n : Nat)
    (s t : S) (step : M.next s = some t)
    (h : M.next (runFor M n s) = none) : boundedTicks M n t < boundedTicks M n s := by
  cases n with
  | zero =>
      change M.next s = none at h
      rw [step] at h
      cases h
  | succ n =>
      rw [runFor, step] at h
      rw [boundedTicks_tick M n s t step, boundedTicks_stable M n t h,
        Nat.add_comm 1]
      exact Nat.lt_succ_self _

/-- A finite, explicit local ranking on reached negative states. -/
def rankingFromDeadline {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (D : UniformDeadline G)
    (C : Input) (negative : G.Negative C) : Ranking (ReachMachine G C) where
  reserve q := boundedTicks G.machine
    (D.coefficient * (G.inputBits C + 1)^D.degree) q.val
  decrease q r step := by
    have actual := reached_projection G.machine (G.initial C) q
    rw [step] at actual
    have sourceStep : G.machine.next q.val = some r.val := actual.symm
    exact boundedTicks_decreases G.machine _ q.val r.val sourceStep
      (reached_halted_by_same_deadline G.machine _ (G.initial C) (D.hit C negative)
        q.val q.property)

def reserveFromDeadline {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (D : UniformDeadline G) :
    UniformReserve G where
  coefficient := D.coefficient
  degree := D.degree
  positive := D.positive
  ranking := rankingFromDeadline D
  initial_bound C _h := boundedTicks_le G.machine _ (G.initial C)

/-- Exact judgement equivalence, with one original program and fixed c,d. -/
theorem reserve_target_iff_deadline_target {Input : Type u} {State : Type v}
    (G : GeneratorImplementation.{u,v,w} Input State) :
    UniformReserveTarget G ↔ UniformDeadlineTarget G := by
  constructor
  · exact named_source_bridge G
  · intro ⟨D⟩
    exact ⟨reserveFromDeadline D⟩

theorem converse_keeps_clock {Input : Type u} {State : Type v}
    {G : GeneratorImplementation.{u,v,w} Input State} (D : UniformDeadline G) :
    (reserveFromDeadline D).coefficient = D.coefficient ∧
    (reserveFromDeadline D).degree = D.degree := ⟨rfl, rfl⟩

end H24OperationalBridge

/-- Natural-valued frontier credit, with the two original local equations. -/
structure FrontierAccount {S : Type u} (M : BitMachine S) where
  potential : S → Nat
  credit : S → Nat
  charge : S → S → Nat
  balance : ∀ s t, M.next s = some t →
    1 + potential t = charge s t + potential s
  pays : ∀ s t, M.next s = some t →
    charge s t + credit t ≤ credit s

def FrontierAccount.reserve {S : Type u} {M : BitMachine S}
    (A : FrontierAccount M) (s : S) : Nat :=
  A.potential s + A.credit s

theorem FrontierAccount.reserve_step {S : Type u} {M : BitMachine S}
    (A : FrontierAccount M) (s t : S) (h : M.next s = some t) :
    1 + A.reserve t ≤ A.reserve s := by
  change 1 + (A.potential t + A.credit t) ≤ A.potential s + A.credit s
  calc
    1 + (A.potential t + A.credit t)
        = (1 + A.potential t) + A.credit t := (Nat.add_assoc _ _ _).symm
    _ = (A.charge s t + A.potential s) + A.credit t :=
      congrArg (fun x => x + A.credit t) (A.balance s t h)
    _ = A.potential s + (A.charge s t + A.credit t) := by
      rw [Nat.add_comm (A.charge s t) (A.potential s), Nat.add_assoc]
    _ ≤ A.potential s + A.credit s :=
      Nat.add_le_add_left (A.pays s t h) _

def FrontierAccount.toRanking {S : Type u} {M : BitMachine S}
    (A : FrontierAccount M) : Ranking M where
  reserve := A.reserve
  decrease := by
    intro s t h
    apply Nat.lt_of_succ_le
    exact (Nat.one_add (A.reserve t)) ▸ (A.reserve_step s t h)

def putFrontierInH24 {S : Type u} {M : BitMachine S}
    (A : FrontierAccount M) (s : S) :=
  putRunInH24 A.toRanking s

theorem frontier_constructs_actual_clock {S : Type u} {M : BitMachine S}
    (A : FrontierAccount M) (s : S) :
    ticks (sourceRun A.toRanking s) ≤ A.potential s + A.credit s :=
  sourceRun_paid A.toRanking s

structure SignedAccount {S : Type u} (M : BitMachine S) where
  potential : S → Nat
  spent : S → Int
  allowance : Nat
  prefix_cap : ∀ s, spent s ≤ (allowance : Int)
  balance : ∀ s t, M.next s = some t →
    (1 : Int) + (potential t : Int) ≤
      (spent t - spent s) + (potential s : Int)

def SignedAccount.reserve {S : Type u} {M : BitMachine S}
    (A : SignedAccount M) (s : S) : Nat :=
  ((A.potential s : Int) + (A.allowance : Int) - A.spent s).toNat

theorem SignedAccount.reserve_cast {S : Type u} {M : BitMachine S}
    (A : SignedAccount M) (s : S) :
    (A.reserve s : Int) =
      (A.potential s : Int) + (A.allowance : Int) - A.spent s := by
  apply Int.toNat_of_nonneg
  have h := A.prefix_cap s
  omega

theorem SignedAccount.reserve_step {S : Type u} {M : BitMachine S}
    (A : SignedAccount M) (s t : S) (h : M.next s = some t) :
    1 + A.reserve t ≤ A.reserve s := by
  have hs := A.reserve_cast s
  have ht := A.reserve_cast t
  have hb := A.balance s t h
  omega

def SignedAccount.toRanking {S : Type u} {M : BitMachine S}
    (A : SignedAccount M) : Ranking M where
  reserve := A.reserve
  decrease := by
    intro s t h
    have hb := A.reserve_step s t h
    omega

theorem SignedAccount.initial_reserve {S : Type u} {M : BitMachine S}
    (A : SignedAccount M) (s : S) (h : A.spent s = 0) :
    A.reserve s = A.potential s + A.allowance := by
  have hr := A.reserve_cast s
  omega

/-- The bridge is placed in the original H24 constructor by this definition. -/
def putCreditInH24 {S : Type u} {M : BitMachine S}
    (A : SignedAccount M) (s : S) :=
  putRunInH24 A.toRanking s

theorem credit_constructs_actual_run {S : Type u} {M : BitMachine S}
    (A : SignedAccount M) (s : S) :
    ticks (sourceRun A.toRanking s) ≤ A.reserve s :=
  sourceRun_paid A.toRanking s

theorem credit_constructs_initial_clock {S : Type u} {M : BitMachine S}
    (A : SignedAccount M) (s : S) (h : A.spent s = 0) :
    ticks (sourceRun A.toRanking s) ≤ A.potential s + A.allowance := by
  have hb := credit_constructs_actual_run A s
  rw [A.initial_reserve s h] at hb
  exact hb

/-- A polynomial envelope is explicit data; no coefficients are searched for. -/
structure Budget where
  coefficient : Nat
  degree : Nat

def Budget.eval (p : Budget) (n : Nat) : Nat :=
  p.coefficient * (n+1)^p.degree

/-- Primitive-recursive maximum, with elementary constructive order proofs. -/
def joinDegree : Nat → Nat → Nat
  | 0, b => b
  | a+1, 0 => a+1
  | a+1, b+1 => joinDegree a b + 1

theorem joinDegree_left (a b : Nat) : a ≤ joinDegree a b := by
  induction a generalizing b with
  | zero => exact Nat.zero_le _
  | succ a ih =>
      cases b with
      | zero => exact Nat.le_refl _
      | succ b => exact Nat.succ_le_succ (ih b)

theorem joinDegree_right (a b : Nat) : b ≤ joinDegree a b := by
  induction a generalizing b with
  | zero => exact Nat.le_refl _
  | succ a ih =>
      cases b with
      | zero => exact Nat.zero_le _
      | succ b => exact Nat.succ_le_succ (ih b)

def Budget.add (p q : Budget) : Budget :=
  ⟨p.coefficient+q.coefficient, joinDegree p.degree q.degree⟩

theorem add_mul_constructive (a b k : Nat) :
    (a+b)*k = a*k + b*k := by
  induction k with
  | zero => rfl
  | succ k ih =>
      rw [Nat.mul_succ, Nat.mul_succ, Nat.mul_succ, ih]
      exact Nat.add_add_add_comm _ _ _ _

theorem Budget.add_bound (p q : Budget) (n : Nat) :
    p.eval n + q.eval n ≤ (p.add q).eval n := by
  have hp : (n+1)^p.degree ≤ (n+1)^(joinDegree p.degree q.degree) :=
    Nat.pow_le_pow_right (Nat.zero_lt_succ n) (joinDegree_left _ _)
  have hq : (n+1)^q.degree ≤ (n+1)^(joinDegree p.degree q.degree) :=
    Nat.pow_le_pow_right (Nat.zero_lt_succ n) (joinDegree_right _ _)
  change p.coefficient * (n+1)^p.degree + q.coefficient * (n+1)^q.degree ≤
    (p.coefficient+q.coefficient) * (n+1)^(joinDegree p.degree q.degree)
  rw [add_mul_constructive]
  exact Nat.add_le_add (Nat.mul_le_mul_left _ hp) (Nat.mul_le_mul_left _ hq)

def Budget.mul (p q : Budget) : Budget :=
  ⟨p.coefficient*q.coefficient, p.degree+q.degree⟩

theorem Budget.mul_exact (p q : Budget) (n : Nat) :
    p.eval n * q.eval n = (p.mul q).eval n := by
  simp only [eval, mul, Nat.pow_add]
  ac_rfl

/-- The natural frontier version of the complete uniform H24 clock. -/
theorem uniform_frontier_clock
    {Input : Type} {S : Input → Type u}
    (M : (C : Input) → BitMachine (S C))
    (initial : (C : Input) → S C)
    (size : Input → Nat)
    (A : (C : Input) → FrontierAccount (M C))
    (p q : Budget)
    (potential_bound : ∀ C, (A C).potential (initial C) ≤ p.eval (size C))
    (credit_bound : ∀ C, (A C).credit (initial C) ≤ q.eval (size C)) :
    ∀ C, ticks (sourceRun (A C).toRanking (initial C)) ≤ (p.add q).eval (size C) := by
  intro C
  calc
    ticks (sourceRun (A C).toRanking (initial C))
        ≤ (A C).potential (initial C) + (A C).credit (initial C) :=
      frontier_constructs_actual_clock (A C) (initial C)
    _ ≤ p.eval (size C) + q.eval (size C) :=
      Nat.add_le_add (potential_bound C) (credit_bound C)
    _ ≤ (p.add q).eval (size C) := Budget.add_bound p q (size C)

/-- The returned coefficient/degree are fixed before all source inputs. -/
theorem uniform_credit_clock
    {Input : Type} {S : Input → Type u}
    (M : (C : Input) → BitMachine (S C))
    (initial : (C : Input) → S C)
    (size : Input → Nat)
    (A : (C : Input) → SignedAccount (M C))
    (p q : Budget)
    (spent_zero : ∀ C, (A C).spent (initial C) = 0)
    (potential_bound : ∀ C, (A C).potential (initial C) ≤ p.eval (size C))
    (allowance_bound : ∀ C, (A C).allowance ≤ q.eval (size C)) :
    ∀ C, ticks (sourceRun (A C).toRanking (initial C)) ≤ (p.add q).eval (size C) := by
  intro C
  calc
    ticks (sourceRun (A C).toRanking (initial C))
        ≤ (A C).potential (initial C) + (A C).allowance :=
      credit_constructs_initial_clock (A C) (initial C) (spent_zero C)
    _ ≤ p.eval (size C) + q.eval (size C) :=
      Nat.add_le_add (potential_bound C) (allowance_bound C)
    _ ≤ (p.add q).eval (size C) := Budget.add_bound p q (size C)

/-- Construct the exact promised-side source reserve from the frontier fields.
    The fixed implementation and p,q precede all original inputs. -/
def frontierUniformReserve
    {Input : Type} {State : Type u}
    (G : GeneratorImplementation Input State)
    (A : ∀ C, G.Negative C → FrontierAccount (ReachMachine G C))
    (p q : Budget)
    (positive : 0 < p.coefficient + q.coefficient)
    (potential_bound : ∀ C h, (A C h).potential (Initial G C) ≤ p.eval (G.inputBits C))
    (credit_bound : ∀ C h, (A C h).credit (Initial G C) ≤ q.eval (G.inputBits C)) :
    UniformReserve G where
  coefficient := p.coefficient + q.coefficient
  degree := joinDegree p.degree q.degree
  positive := positive
  ranking C h := (A C h).toRanking
  initial_bound C h := by
    change (A C h).potential (Initial G C) + (A C h).credit (Initial G C) ≤
      (p.add q).eval (G.inputBits C)
    exact Nat.le_trans (Nat.add_le_add (potential_bound C h) (credit_bound C h))
      (Budget.add_bound p q (G.inputBits C))

/-- A native frontier account now enters the original H24 constructor directly. -/
def putFrontierBridgeInH24
    {Input : Type} {State : Type u}
    (G : GeneratorImplementation Input State)
    (A : ∀ C, G.Negative C → FrontierAccount (ReachMachine G C))
    (p q : Budget)
    (positive : 0 < p.coefficient + q.coefficient)
    (potential_bound : ∀ C h, (A C h).potential (Initial G C) ≤ p.eval (G.inputBits C))
    (credit_bound : ∀ C h, (A C h).credit (Initial G C) ≤ q.eval (G.inputBits C))
    (C : Input) (h : G.Negative C) :=
  putBridgeInH24 (frontierUniformReserve G A p q positive potential_bound credit_bound) C h

/-- The actual stopped decision receives C; negative evidence is not an input. -/
def decideFromFrontier
    {Input : Type} {State : Type u}
    (G : GeneratorImplementation Input State)
    (A : ∀ C, G.Negative C → FrontierAccount (ReachMachine G C))
    (p q : Budget)
    (positive : 0 < p.coefficient + q.coefficient)
    (potential_bound : ∀ C h, (A C h).potential (Initial G C) ≤ p.eval (G.inputBits C))
    (credit_bound : ∀ C h, (A C h).credit (Initial G C) ≤ q.eval (G.inputBits C))
    (C : Input) : Decidable (G.Negative C) :=
  decideNegative (bridgeDeadline
    (frontierUniformReserve G A p q positive potential_bound credit_bound)) C
