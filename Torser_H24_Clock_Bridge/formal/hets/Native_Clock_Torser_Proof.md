# The native torser judgment for an actual clocked shortest-verifier run

## 1. The judgment and the object it retains

Fix a deterministic bit machine (A), its original CNF input encoding, and
its actual primitive transition convention. A primitive transition reads and
writes a fixed finite set of tape-head bits, changes finite control, and moves
heads by at most one cell. The machine is fixed before the input. Literal
indices, clauses, assignments, output words, and verification steps belong to
its ordinary tape computation. Access to a distant encoded bit is performed
by that computation; it is not an additional unit-cost random-access primitive.

Write (s\mathrel{\leadsto_A}s') for **one such executed transition**. A
recorded configuration is

\[
 x=(C,s,H),\qquad \tau(x)=|H|.
\]

Here (C) is the unchanged original input and (H) is the chronological
history of executed primitive events. A history event has a fixed finite
alphabet depending on (A): previous control, overwritten head symbols and
head directions suffice. It does not contain a copied whole tape. Appending
one event is performed at the end of a separate history tape. The inverse
restores the old heads, symbols and control from the last event. Consequently

\[
 f_A(C,s,H)=(C,s',H\mathbin{\|}e_A(s))
\tag{1}
\]

is injective on its live domain. The inverse is defined on its actual image.
A halting state has no executed successor in this relation.

The source clock is the **marked natural number** (|H|). It is not obtained
by declaring arbitrary-precision integer addition a single transition. It may
remain the length of the event stream. If a program materializes its binary
numeral, copies the complete history, evaluates a matrix entry, prints a proof,
or runs another verifier, all those instructions are additional executed
events. Equation (1) is a record-preserving simulation: a fixed reversible
implementation uses a fixed number of local bit transitions per source step,
with its own initial/final overhead. Source ticks and implementation ticks are
two explicitly related counts, not silently identified numbers.

The new native judgment is

\[
 \mathsf{NT}_A(C;x\xRightarrow[p]{,k,}y).
\tag{2}
\]

It means that (p) is a derivation from the rules below, its represented
execution starts at (x), ends at (y), retains (C), and contains exactly
(k) original primitive bit transitions. A terminal version is

\[
 \mathsf{NTMin}_A(C;q,k):=
 \sum_{x,y,p}\mathsf{NT}_A(C;x\xRightarrow[p]{k}y)
 \times\mathsf{Initial}_A(C,x)\times\mathsf{Halt}_A(y)
 \times[\mathsf{output}(y)=q]\times\mathsf{Shortest}_{V_*}(C,q).
\tag{3}
\]

The final field is the original fixed-verifier minimum, not a native surrogate.
The existing source has

\[
 V_*(C,q)\iff
 q=1\,0^{n+1}\quad\lor\quad
 \exists a\in\{0,1\}^n\;(q=0a\ \land\ C(a)=1).
\tag{4}
\]

Its structural constructor already proves that its emitted code is a minimum
among **all** words accepted by this (V_*). The new construction transports
that proof and the actual execution; it does not assume a polynomial SAT
algorithm.

## 2. Rules that construct the native execution proof

The proof syntax is generated by the following constructors.

**Identity.** The unchanged configuration has a zero-transition proof:

\[
 \frac{}{\mathsf{NT}_A(C;x\xRightarrow{0}x)}.
\]

**Actual tick.** A literal transition of the fixed machine gives

\[
 \frac{s\leadsto_A s'}
 {\mathsf{NT}_A(C;(C,s,H)\xRightarrow{1}
                  (C,s',H\mathbin{\|}e_A(s)))}.
\]

**Costed composition.** Matching middle configurations give

\[
 \frac{\mathsf{NT}_A(C;x\xRightarrow{k}y)\qquad
       \mathsf{NT}_A(C;y\xRightarrow{l}z)}
 {\mathsf{NT}_A(C;x\xRightarrow{k+l}z)}.
\]

The displayed addition is an equality of mathematical grades. This constructor
does not execute a hidden arbitrary-precision addition at unit cost. If a
running implementation computes that grade, its computation is represented by
further ticks.

**Pure change of presentation.** A proved equality of two descriptions of the
same retained record may replace one description by the other at zero added
execution cost. It changes neither (s), (H), nor the original output. A
real conversion program, frame-update instruction, matrix materialization or
copy is represented by its ticks instead. This rule is therefore unavailable
for an unevaluated coefficient operator.

**Local reserve.** A natural reserve (\Phi) and natural slack (\eta) satisfy
the upper-work rule precisely when

\[
 1+\Phi(f_Ax)+\eta(x)=\Phi(x)
\tag{5}
\]

at the actual live state. It is tight when (\eta(x)=0). For a macro of
already established cost (c(x)), replace (1) by (c(x)). No assertion
that such a reserve exists on all inputs is built into this rule.

**Terminal readback.** A valid halting execution, an equality of its actual
output with the output of a checked original receipt, and the existing
structural receipt theorem construct (3). In the source notation the premise
is

\[
 \mathsf{rrOK}(C,\epsilon,n,h),\qquad
 \mathsf{output}(y)=\mathsf{rrEmit}(C,h).
\]

`rr_root_receipt_gives_minimum` then supplies the last field of (3). This is
a mathematical proof rule. It does not request an uncharged runtime oracle
that tests whether an arbitrary code is shortest. Any actual checker called
by (A) has already contributed its transitions to (H).

### The complete clock invariant

Induction on these constructors proves

\[
 \tau(y)=\tau(x)+k.
\tag{6}
\]

For identity, (6) is addition by zero. For a tick it is the defining history
extension. For composition, substitute the two induction hypotheses and use
associativity of natural addition. Presentation equality changes no record.
Terminal readback adds no execution. The same induction proves equality of
the original input at the two endpoints and exact preservation of the output
field.

Applying the local reserve rule at every actual tick and inducting on the
same execution gives

\[
 k+\Phi(y)+\sum_{x_i\text{ executed}}\eta(x_i)=\Phi(x).
\tag{7}
\]

Every term on the left is a marked natural number. Thus (k\le\Phi(x)).
This is an **upper** execution bound. The H24 lower calibration has the
different convention

\[
 \mathsf{ruleCost}+V(\mathsf{premises})
       =V(\mathsf{conclusion})+\mathsf{lowerSlack}.
\tag{8}
\]

The slacks in (7) and (8) are not interchangeable. A tight supplied execution
has zero reserve slack. The H24 agent's `H24OperationalBridge` uses the actual
bit-machine transition, structural rank, calibration and policy to construct
`putRunInH24`; this native judgment is its record-preserving realization.

For a concrete finite instruction word, the number of remaining primitive
instructions is a decreasing structural rank; each actual tick removes its
head. This proves termination of the proof constructor by list structure.
For a general shortest-code generator, its actual source termination/ranking
argument is retained. The number of recursive CNF cuts, output length (n+1)
or (n+2), matrix dimension four and number of frames six are not substituted
for its actual work rank.

## 3. The simultaneous sparse native matrix

Let (X) be the set of complete recorded contexts, including the original
input, machine tapes/control, history, requested output and proof fields.
Use the algebraic free module with basis (e_x). For a recorded injective
partial map (f:X\rightharpoonup X) and its marked natural cost (c(x)), set

\[
 P_f e_x=\begin{cases}e_{f(x)}&x\in\operatorname{dom}f,\\0&\text{otherwise},\end{cases}
 \qquad
 W_{f,c}e_x=\begin{cases}c(x)e_{f(x)}&x\in\operatorname{dom}f,\\0&\text{otherwise}.
 \end{cases}
\tag{9}
\]

Their coefficients lie in the ring (R) of row-and-column-finite matrices
over (\mathbb Z_2), or first over (\mathbb Z_{(2)}). Every row and column
in (9) has at most one nonzero entry. Matrix multiplication remains defined
and row-and-column finite; transpose defines a compatible coefficient
involution. Recording the history is what provides this convenient adjoint
domain. A general many-to-one map with infinitely many preimages would require
a different module/adjoint declaration and is not silently admitted here.

Use the original native algebra with six operator coefficients:

\[
 (t,b,B)(u,c,H)=(tu,\;tc+bu-2bc,\;BH),
\]

\[
 \rho(t,b,B)=
 \begin{pmatrix}
 t-2b&0&0&0\\
 0&B_{00}&B_{01}&0\\
 0&B_{10}&B_{11}&0\\
 b&0&0&t
 \end{pmatrix}.
\tag{10}
\]

All products keep their written order in (R). The decoder reads entries
((4,4),(4,1)), and the middle two-by-two block. Hence

\[
 \delta\rho=\mathrm{id},\qquad \rho(ab)=\rho(a)\rho(b).
\tag{11}
\]

For completeness, the lower-left product is

\[
 b(u-2c)+tc=bu-2bc+tc,
\]

and the upper-left product is

\[
 (t-2b)(u-2c)=tu-2(tc+bu-2bc).
\]

The bottom-right product is (tu), the middle block is (BH), and all other
entries remain zero. These are the full multiplication proof, with no
commutation of contextual operators. Associativity follows by (11) and
injectivity of $\rho$, or by expansion in the free associative algebra.

The clocked native operation is

\[
 \mathcal C(f,c)=
 \rho\left(P_f,0,
 \begin{pmatrix}P_f&W_{f,c}\\0&P_f\end{pmatrix}\right).
\tag{12}
\]

Its sparse source column has one destination context, the complete original
record (f(x)); the off-diagonal middle coefficient at that destination is
the source-origin integer (c(x)). It retains both the operation and its
clock. It does not compress the arbitrary context into four scalar integers.

For composable partial maps (f,g), direct evaluation on (e_x) gives

\[
 P_gP_f=P_{g\circ f},\qquad
 P_gW_{f,c}+W_{g,d}P_f=W_{g\circ f,\,c+d\circ f}.
\]

Multiplying (12) therefore proves the exact fusion law

\[
 \mathcal C(g,d)\mathcal C(f,c)
       =\mathcal C(g\circ f,c+d\circ f).
\tag{13}
\]

Induction on an actual primitive run gives its full native matrix and the
exact sum of its actual costs. In particular, for a fixed cost coordinate,

\[
 U(k)=\begin{pmatrix}1&k\\0&1\end{pmatrix},\qquad
 U(l)U(k)=U(k+l),\qquad
 K(k)=\rho(1,0,U(k)).
\tag{14}
\]

The upper reserve (5) is represented by

\[
 K(1)K(\Phi(f_Ax))K(\eta(x))=K(\Phi(x)).
\tag{15}
\]

Equality reflects the original integer equation because
(\mathbb N\hookrightarrow\mathbb Z_2) is injective. Order and nonnegativity
are still predicates on the original marked naturals. At a finite dyadic
aperture, the numerical residue alone can wrap; retain the natural sidecar or
supply a bit aperture exceeding the proved bound before using a numerical
decoder. No order relation on arbitrary (2)-adic numbers is asserted.

## 4. The actual six frames and their bitorsor

Use the archived supported locus

\[
 F=\{(v,\ell)\in\mathbb F_2^2\times(\mathbb F_2^2)^*:\ell(v)=1\},
\]

with its six frames (G=\mathrm{GL}_2(\mathbb F_2)\cong S_3). The native
generators are the original coordinate tuples

\[
 r=(1,0,0,-1,1,-1),\qquad
 s=(1,1,0,1,1,0).
\]

They satisfy (r^3=s^2=1) and (srs=r^{-1}); the six elements are
(1,r,r^2,s,sr,sr^2). Their four-by-four matrices are exactly (10).
The six coordinate columns have determinant of absolute value (27), a
dyadic unit, so the group-coefficient representation remains faithful over
the contextual operator algebra.

For local frame choices (\gamma_X(x),\gamma_Y(y)), let

\[
 \Gamma_X=\bigoplus_x\rho(\gamma_X(x)).
\]

The same native clocked operation in these frames is

\[
 \widehat{\mathcal C}_{Y,X}(f,c)
        =\Gamma_Y\mathcal C(f,c)\Gamma_X^{-1}.
\tag{16}
\]

The source and target frames are retained in the record. Removing the two
specified factors recovers (12), hence the exact original operation and cost.
For a second operation the intermediate factors cancel:

\[
 \widehat{\mathcal C}_{Z,Y}(g,d)
 \widehat{\mathcal C}_{Y,X}(f,c)
 =\widehat{\mathcal C}_{Z,X}(g\circ f,c+d\circ f).
\tag{17}
\]

This is the explicit native cocycle square. Source anchor (a), middle anchor
(b) and target anchor (c) give
((c^{-1}kb)(b^{-1}ha)=c^{-1}kha). No global choice of an origin is needed
for the associated-module construction. If a frame is physically updated by
an instruction, that instruction's bit work is charged. Equation (16) as an
equality of presentations executes no instruction.

Thus the sparse representation is simultaneously a four-by-four native
operator matrix, a six-frame bitorsor map, and the costed original run. Rank
four is the fibre rank; it is not the dimension of the contextual state space
or an execution bound.

## 5. Gram dagger, operational inverse and the clock shear

The coefficient involution is transpose on row-and-column-finite contextual
operators. Extend it to conjugate transpose (M^*) on the four-by-four block.
Use the original full Gram matrix

\[
 J=\begin{pmatrix}
 1&0&0&1\\0&2&-1&0\\0&-1&2&0\\1&0&0&2
 \end{pmatrix},\qquad
 J^{-1}=\begin{pmatrix}
 2&0&0&-1\\0&2/3&1/3&0\\0&1/3&2/3&0\\-1&0&0&1
 \end{pmatrix}.
\]

Its determinant is (3), so the inverse is integral at the dyadic prime.
Define (M^\dagger=J^{-1}M^*J). Multiplying gives

\[
 \rho(t,b,B)^\dagger
   =\rho(t^*,b^*,G^{-1}B^*G),\qquad
 G=\begin{pmatrix}2&-1\\-1&2\end{pmatrix}.
\tag{18}
\]

The same multiplication proves (J^{-1}J=JJ^{-1}=I), whence

\[
 (MN)^\dagger=N^\dagger M^\dagger,
 \qquad(M^\dagger)^\dagger=M.
\tag{19}
\]

The actual frame matrices obey (\rho(g)^\dagger=\rho(g^{-1})).
Therefore frame transport is unitary in this metric, and

\[
 (\Gamma_Y M\Gamma_X^{-1})^\dagger
       =\Gamma_X M^\dagger\Gamma_Y^{-1}.
\tag{20}
\]

The unweighted recorded transition (P_f\otimes I_4) is a partial isometry:
its dagger followed by itself is the projection on its actual source domain;
the opposite product is projection on its actual image. This is the inverse
of the history-preserving step on that image.

The clock shear is different. Direct calculation gives

\[
 U(k)^\dagger_G=
 \begin{pmatrix}1+2k/3&-k/3\\4k/3&1-2k/3\end{pmatrix},
 \qquad U(k)^{-1}=U(-k).
\tag{21}
\]

These generally differ. The complete clocked matrix has an exact dagger and
an exact decoder, but recording elapsed work is not declared a unitary data
operation. Reading the adjoint does not mean executing a negative-time run.
The inverse (U(-k)) is an algebraic comparison; actual reverse execution,
when requested, consists of its own positive-cost primitive steps.

## 6. Fredkin and Toffoli are actual local operational blocks

The inherited source uses

\[
 \mathrm F(c,a,b)=
 \begin{cases}(0,a,b)&c=0,\\(1,b,a)&c=1,\end{cases}
 \qquad
 \mathrm T(c,a,t)=(c,a,t\oplus ca).
\tag{22}
\]

Both are involutions on their actual three original wires. The source proves
these equations by the Boolean constructors and retains the challenged
original variable and clause labels. With fixed constants, Toffoli returns
AND, NAND and NOT, and Fredkin returns OR and the marked mux. This is the
existing `CechReversibleGates` interface, not a newly postulated gate action.

For a fixed machine (A), its finite local transition table is a finite
Boolean function of the control and head symbols. Write each output bit by
its finite truth formula. Each AND is obtained by Toffoli on a clean target,
NOT by a controlled constant wire, and copying by the corresponding XOR gate
with constant control. Retain inputs and old control until outputs and the
finite history event have been recorded; reverse temporary gates to clean
workspace. Fixed head moves are genuine local tape moves. This constructs a
reversible finite block for every source transition.

All truth-formula, workspace and motion sizes depend on the fixed machine,
not on (C). Let its actual compiled bit-transition list have length
(\kappa_A(e)). The native matrix of that block has cost
(\kappa_A(e)) by (13), not cost one merely because it has one source name.
For a source run (e_1,\ldots,e_k),

\[
 W_{\widehat A}(C)=W_{\rm init}(C)
     +\sum_{i=1}^k\kappa_A(e_i)+W_{\rm final}(C).
\tag{23}
\]

In particular (kappa_A=\max_e\kappa_A(e)) gives the proved simulation
bound. Setup, output, verification and readback in this implementation are
included in the two overhead terms or in the event lists. A request to treat
an arbitrary decoded program as an input changes the machine to an interpreter
and uses that interpreter's actual step costs. No nonuniform constant is
allowed to vary with the individual CNF.

## 7. The shortest-verifier bridge is now a native H24 conclusion

Take the fixed actual implementation of the original structural CNF
constructor and its source correctness proof. For every input, its finite
executed run supplies (2). Its original receipt theorem supplies the minimum
field in (3). The terminal native decoder returns

\[
 (C,q,H,k,\pi_{\rm run},\pi_{\rm min})
\]

exactly; in particular it returns the original assignment when (q=0a), or
the original negative proof when (q=1\,0^{n+1}) is minimum. The minimum code
length is (n+1) or (n+2); the execution work is (k). Both are retained
and they need not be equal or polynomially related without a further proof.

The H24 operational rules apply to this judgment itself. Encoding every
premise, conclusion, transition and grade commutes with its constructors by
(11), (13), (17) and the terminal source return. Induction transports every
derivation. The decoder gives the converse on the admitted native image.
Therefore a supplied source calibration and tight structural policy give a
native calibration and the **constructed** H24 proof through
`H24OperationalBridge.putRunInH24`. The theorem compares arbitrary proofs in
that declared operational grammar. It does not search for a competing proof.
The separate fixed-verifier theorem still compares all words accepted by
(V_*), because (4) and its full original proof remain unchanged.

A uniform polynomial **envelope judgment** contains concrete data:

1. one fixed generator implementation and its source-to-native simulation;
2. its initial-state constructor and original-input/output maps;
3. the reachable-state invariant, natural reserve and decreasing rank;
4. a proof of the local tick inequality (5) for every enabled state admitted
   by that invariant;
5. preservation of the invariant, rank-based termination, and the original
   terminal receipt/readback theorem;
6. one pair (c,d), fixed before (C), and a proof
   (\Phi(x_0(C))\le c(|\operatorname{enc}C|+1)^d), with all simulation,
   checking and output overhead included.

Folding these fields by (7) **constructs** the all-input clock proof; it is
not a bare assertion that an unnamed terminal grade happens to be small.
For the negative-only clock, the invariant/ranking fields have exactly that
negative-input scope and the sound checked-negative hit rule of the fixed monitor.
The stopped decider, the ordinary shortest-code producer obtained by original
pin queries, and their native returns are then the existing explicit
clock/shortest-verifier constructions. The present bridge supplies the closed
native algebra, operational proof rules, same-run clock invariant and H24
transport. It does not supply an unproved all-CNF polynomial envelope for the
particular structural generator.

is asserted to be inhabited. The source clock's precise convention is retained.

free execution-proof syntax whose endpoints contain the encoded original

implemented for free. The nontrivial state, coefficient, frame and clock maps
are the explicit constructions above. Standard coefficient/adjoint
interpretation laws are separately named.
They are proved concretely above and by the exact free-associative reflection
checks; none asserts polynomial SAT or a source execution bound.
